# Smart Resume Builder

## Run
1. Extract this folder.
2. Open `index.html` in a modern browser (Chrome/Edge/Firefox).
3. Edit the fields; the resume preview and suggestions update automatically.
4. Select **Export / Print PDF**, then choose **Save as PDF** in the browser print dialog.

## Features
- Editable personal, education, skills and project sections
- Live resume preview
- Basic rule-based improvement suggestions
- Print stylesheet for PDF export

## Technology
HTML5, CSS3 and vanilla JavaScript. This self-contained version uses local browser processing and does not require a server, database or API key. The suggestions are rule-based, not generated by a hosted AI model.
